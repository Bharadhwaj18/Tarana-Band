Official website for Tarana, with a public site and a private admin CMS the band uses to run everything fans see.

**Live:** https://taranaband.in/

## Public site

Tour dates, videos, gallery, merch store with ordering, contact/booking enquiries.

## Admin CMS

Dashboard, merch inventory and order management (ship/cancel flows), tour and gallery editors, homepage content, member profiles, contact submission inbox, transactional email via Resend.

## Stack

Next.js 14, React 18, TypeScript, Supabase (auth + Postgres), Tailwind CSS, Resend, zod.
